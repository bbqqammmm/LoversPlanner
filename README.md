# 📔 恋人手帐 Lover's Planner

**简体中文** · [繁體中文](README.zh-TW.md)

给 [TauriTavern](https://github.com/Darkatse/TauriTavern) / SillyTavern 用的长期记忆扩充。
聊了几千层之后，角色还记得你们去过哪里、约好了什么、哪天是纪念日，而且发送去的 token 不会越滚越大。

- **摘要**：每一层 AI 回复写一小段摘要，旧的原文不再整段发送，只送摘要。
- **压缩**：摘要再往上压成章、卷、部…（没有层数上限），越旧越精简。
- **记事**：人物、物件、约定、待办，自动记下、自动更新，完成的收进「已完成」。
- **行事历**：故事里的日期、约定的日子、纪念日、生理期、亲密的日子。
- **回忆录**：值得珍藏的时刻，偶尔让角色自然地想起「还记得那天…」。
- **补建**：聊了很久才开始用？一键把旧楼层的摘要和记事补起来。

界面有繁体中文、简体中文、English。

## 安装和更新

**安装**：TauriTavern／SillyTavern → 扩充功能 → 安装扩充 → 粘贴：

```
https://github.com/bbqqammmm/LoversPlanner
```

**更新**：在扩充功能管理里按更新。默认会在更新后**自动刷新**（等摘要、生成都做完、大窗口关着时才会刷新，输入框里打到一半的字会保留）。不想要可以到「设置 › 一般」关掉。

目前的版本号写在大窗口标题旁边，和「设置 › 一般」最下面。

**更新了什么**：更新后，魔术棒菜单和扩充设置里的「恋人手帐」旁边会有红色的 **NEW**；打开大窗口，最上面有一张卡片写着这次添加和修正了什么。按「知道了」就收起来，下次有新版本才会再出现。以前每一版的记录在「设置 › 一般 › 更新记录」。新安装的不会跳。

## 第一次使用：建议的设置步骤

打开方式：点输入框旁的 **魔术棒** → **恋人手帐**，会打开大窗口。也可以在扩充设置面板里按「打开恋人手帐」。

1. **模型来源**（设置 › 模型来源）
   摘要要调用模型。建议用**自订 API**，接一个便宜、不会「先思考」的模型，例如 DeepSeek 的 `deepseek-chat`。用酒馆的主 API 也可以，但主模型通常比较贵。
   填好网址、密钥，按「拉取模型」选模型，再按「测试」确认能用。
2. **摘要时跳过的内容**（设置 › 摘要时跳过的内容）
   在「AI 楼层用到的标签」选扫描范围（最新 2 层、最新 30 层或全部），看你的回复里有哪些标签（状态栏、思维链、生图提示、排版…），把用不到的设成「不读」。
   状态栏里如果有日期、时间、地点，可以设成「**只当参考**」：不当正文，但让模型知道故事日期。
   这一步做好，能省下非常多 token。
3. **记录项目**（设置 › 记录项目）
   勾选要记哪些：时间、地点、出场人物、人物、物件、约定、待办，以及人物要记哪些字段。
4. **行事历**（设置 › 行事历）
   想记故事日期就开着。如果故事一开始没写日期，可以填「故事开始日」。
5. **摘要模式**（设置 › 摘要）
   - 每回正文结束后自动摘要（最省心）
   - 开始下回前自动摘要（你发送下一句时才摘上一层，重新生成时不会白摘，比较省）
   - 手动
6. **已经聊很久了？** 到「摘要」分页按「**补建旧楼层**」，见下面的[补建](#补建旧楼层)。

## 界面导览

### 聊天里：每条 AI 回复下面的摘要区块

点一下展开，可以看到：日期、时间、地点、出场人物、摘要、这一层造成的记事变化（每条都能撤销）、是哪个模型写的。
按钮：**编辑**、**重做**、**👻 跳过**、**⭐ 小剧场**、**💝 收藏成回忆**；重做过的会有「**其他版本**」可以比较、换回来。

**🔍 这一回送了什么**：AI 回复生成时，恋人手帐送了哪些记事（每条写为什么：主角、提到名字、钉选、最近变动、意思相近几 %）、找回了哪些旧楼层（点楼层号可以跳过去）、让角色想起哪条回忆，以及矢量有没有正常运作、这回新转了几段、注入和省下多少 token。每个 swipe 各记各的；记的是发送那一刻的样子，之后改记事也不会变。角色忘了某件事时，点开就知道是没送到，还是送了但角色没用上。

### 大窗口

| 分页 | 内容 |
|---|---|
| 摘要 | 所有楼层的摘要，依章、卷、部收起来；筛选、搜索、多选、补建、发送预览 |
| 人物 | 人物数据（可以指定谁是 user／char） |
| 物件 | 两人的所有物，数量可以直接 −／＋ |
| 行事历／约定 | 月历在上面，下面是约定和待办 |
| 回忆录 | 收藏的时刻 |
| 已完成 | 完成或用掉的记事，可以还原 |
| 设置 | 所有设置 |

右上角：**🩺 检查**（找出没摘要、失败、过期、可疑的地方，可以一键修正）、**🔍 总搜索**。

标题列会写上次发送时「注入约 N tokens，省下原文约 N tokens」。

## 功能说明

### 摘要

- **重做**：不满意就重做，旧的那一版会存起来（最多 5 个），在「其他版本」里比较，按「用这一版」换回来。可以拿来比较不同模型。
- **👻 跳过**：不重要的楼层（OOC、闲聊）可以跳过：不摘要、不调用模型，原文也不再送。
- **⭐ 小剧场**：番外、小剧场、IF 线用这个：不写进正剧摘要、原文也不再送，但会读一次，把值得珍藏的回忆、之后正剧也算数的约定和待办记下（只会添加，不会改动人物、物件）。小剧场的回忆在回忆录里会标「小剧场」。
- **多选**（摘要分页 › 多选）：一次摘要、重新摘要、👻 跳过、⭐ 小剧场（和取消），或把连续的楼层压成一章。
- **隐藏 👻**（摘要分页）：跳过的楼层不列出来（⭐ 小剧场照样列）；筛选「👻 跳过」时还是看得到。夹在章和章之间的跳过、小剧场楼层会放在它所在的那一章里。
- **发送预览**（摘要分页最上面）：看这次会送给角色什么、各部分大约多少 token。

### 压缩：章、卷、部…

已经摘要好的旧楼层，每 10 层压成一**章**，每 5 章压成一**卷**，再往上每 5 个压成**部**、**纪**…（数量可以在「设置 › 压缩」调）。送给角色时只送最上层还有效的那一份，越旧越精简。

- 压缩时模型会顺便归纳 1～2 个主要地点，时间会补上日期。
- 下面的摘要改过，上面的章、卷会变成「**过期**」，送的时候自动改用下一层。
- 重新压缩一直失败的话，可以按「**保留现在的总结**」（不调用模型，拿掉过期标记），或在筛选「过期」「失败」时「全部保留」。

### 隐藏和注入

恋人手帐发送时会把**已经摘要好的旧楼层原文拿掉**，换成摘要和记事；最新 2 层一定保留原文。

- 注入位置（设置 › 注入）：默认放在最新原文前面。
- **也用酒馆的「隐藏」标起来**（设置 › 隐藏，默认关）：再用酒馆自己的隐藏把这些楼层标起来，酒馆算的 token、其他扩充看到的聊天也不含它们。摘要过期时会自动取消隐藏。只动恋人手帐自己标的，你自己 `/hide` 的不会被碰。
- 你自己隐藏的楼层，照样算楼层、摘要照样送。

### 记事

**人物**：名字、别称、身份／职业、年龄、生日、和 user 的关系、和 char 的关系、外貌特征、当前衣着、当前状态、性格、喜欢、不喜欢、习惯／口头禅、重要经历、备注（不要的字段可以在「记录项目」关掉）。
- 人物卡上可以按「**设为 user／设为 char**」指定主角；没指定时用名字自动认。
- 重复的人物可以用 🩺 检查合并，被合并那条后来的更新会自动并过去。

- **📇 从人设填写**（人物区块上方）：读角色卡和你的 persona，把 {{char}} 和 {{user}} 的基本数据整理好（一次调用）。这些字段标「**人设**」，**不会再送给角色**（角色卡本来就会送，不重复花 token），只在摘要时给模型参考；故事里变了（例如剪了头发）才更新，变成一般字段照常送。改了角色卡可以再按一次，故事中改过的字段不会被盖掉。
- **🌍 从世界书填写**（人物区块上方）：读角色卡绑定的、内嵌的和这个聊天绑定的世界书，勾要用的条目（已经记下的人物会先勾好），模型会挑出人物条目整理成字段，同样标「人设」、不重复送。每 8 条一次调用。
- 状态只记会持续的（20～40 字），正在发生的事写在摘要里；备注、经历不写发生过的事（那些在摘要和回忆录里）。已经写得太长的，🩺 检查会列出来，按「**请模型整理**」缩短：备注里的回忆，回忆录已经有的直接删，没有的搬进回忆录。

**物件**：只记两人的所有物，数量、在谁手上。

**约定／待办**：
- 短标题（15 字内）、完整内容、和谁、原文说的时间、**预定日期**（明天、下周三…会换算成实际日期）。
- 卡片上会标「📅 10-28 周三・4 天后」，过期的是红色。
- 可以依预定日期或约定日期排序，筛选「N 天内到期／已过期／没有日期」。
- 旧的约定没有短标题的话，上方有「补标题」按钮。
- 约定要有具体要做的事；「我会一直陪着你」这种没有具体事情的承诺，会收进回忆录（连同是在什么情况下说的）。
- 完成后收进「已完成」，会写完成于哪天、已过几天、**怎么完成的**。

**只发送相关的**（设置 › 只发送相关的＋回忆召回）：记事很多时，只送和现在聊的内容有关的（主角和钉选的一定送）。可以另外置矢量模型（例如硅基流动的 `BAAI/bge-m3`）让比对更准。比对名字时不算 {{char}} 和 {{user}}（到处都是他们的名字），所以和他们之间的约定要靠矢量、最近有变动、钉选或快到期才会送。

### 行事历

模型摘要时会推算每一层是故事里的哪一天，并记下：
- 🎂 纪念日／生日、💕 亲密的日子（次数）、🩸 {{user}} 的生理期
- 有日期的安排都记成约定／待办（预定日期），标在月历上（🤝／📝），快到的会提醒角色。以前的「📌 行程」打开聊天时会自动转成约定。
- 点月历上的某一天，可以直接添加那天的约定或待办。

**生理期**：只记剧情明确提到的开始和结束，不需要填周期。
- 可以开「**推算下次生理期**」（默认关）：用最近 6 次周期的最短～最长，给一个范围，不给单一日期；也可以推算排卵期。
- 开了推算，快到、晚了、很久没来、可能在排卵期时，会用不确定的语气告诉角色。只是故事用的估计，不是医疗依据。

只把「今天」和「接下来几天」的事送给角色，不会把整本行事历塞进去。

**🎂 纪念日清单**（行事历／约定分页，月历下面）：全部的纪念日、生日，写着日期和还有几天。剧情里记到好几次的同一天只列一次。上面直接填月、日和名称就能添加；每一条都能改、删（剧情里记错的也可以删）。

### 回忆录

- 摘要时模型会挑真正值得珍藏的时刻（宁缺勿滥），你也可以在摘要区块按「💝 收藏成回忆」。
- 小剧场、番外默认不写进正剧摘要，但有意义的可以收进回忆录。
- **想起过去**：大约每 10 回，随机挑 1～2 条够旧、最近没提过的回忆，让角色「可以自然地提起，不勉强」。
- 回忆录不会被压缩。
- 开同角色的新聊天时，回忆录可以复制带走（新聊天有一份，可以各自改）或实时共享（一直读旧聊天最新的回忆）。带来的回忆会写「从「某聊天」带来」。

### 小彩蛋

- **📖 那年今日**：故事里的「今天」碰到以前的同一天（一年前、或回忆录里几个月前的同一天），打开大窗口会看到当时的回忆。可以按「💭 让角色想起」，下一回角色会自然地提起；或按「收起」，同一个故事日不再出现。
- **🎂 纪念日**：行事历里的纪念日、生日那天，大窗口最上面会写今天是什么日子，第一次打开时飘一阵花瓣。
- **🎉 里程碑**：一起写到 100、500、1000、2000、3000…层时，有个小庆祝（第一次打开时已经超过的不补）。
- **🤫 还有一个藏起来的**，找找看～

都不会调用模型、不花钱。系统开了「减少动态效果」时不会飘花瓣。

### 带走／共享（设置 › 记忆范围）

同一个角色开新聊天时，可以选择把人物、约定、摘要、**回忆录**等「复制带走」或「实时共享」，也可以从别的聊天导入。新聊天可以有一段「前情提要」（浓缩版或原样）。摘要有带的话，**生理期、亲热、纪念日**也会一起带过去（v0.13.33 起）。在那之前就带过来的聊天，行事历上方会问要不要「补带行事历」，按一下就从旧聊天读过来，不用打开它。

### 📦 旧聊天整理（摘要分页）

很长的旧聊天打开会卡，这里**不用打开**就能读它：按「📦 旧聊天整理」，勾选同一个角色的旧聊天（可以勾好几个），按「读取」。旧聊天档不会被改。

- 照**故事日期**分天：每天几层、已经摘要／还没摘要几层、原文多长、写成日记大约多长，太长的一天会切成几段。日期用恋人手帐的摘要；没有就借 Horae 记的日期。
- 分支聊天重复的消息只算一次。好几个聊天照故事日期排成**同一条时间线**；同一天好几个聊天都写到（可能是 IF 线）会框起来提醒，写日记前可以每天选「都用」或「只用某一个」。
- **行事历**：旧聊天记到的生理期、亲热、纪念日，按「带进这个聊天」就会出现在现在的行事历和纪念日清单（重复按不会重复带）。
- **📖 写成日记**：读完之后选写法（**自然**：像回忆、有心情；**精简**：像记录、比较短），按「开始写日记」。会先显示要调用几次、发送多少字。日记在背景一段一段写，聊天和摘要优先，发送消息不用等日记写完。已经有恋人手帐摘要的楼层送摘要，不用重读原文；思考过程、状态栏等照「设置 › 摘要时跳过的内容」拿掉。OOC 不会写进日记。
- **📖 日记**（摘要分页）：一天一列，点开看全文、时间地点、这天的重点。可以**编辑**、**重写**、**换另一种写法重写**、**删除**。
- **🗜️ 再压一次**：勾要留下的重点、选压到原本的 70%／50%／30%。原版一直留着，可以「换回原版」或删掉压缩版。压到一半以下会提醒（测试结果：中等的事大多会不见）。也可以把「超过多少字」的日子一起压。
- 重写和换写法要用到旧聊天的内容：刷新过的话，先在「📦 旧聊天整理」再读一次。再压一次只用日记本身，不用重读。
- 每天会记着是哪个聊天写的。已经用**别的聊天**写好的日子不会被盖掉：会先列出来，你可以选「照这次读的重写」或「保留原本的」。想把两个聊天合在一起写，就把它们一起勾起来再读一次。
- **📨 送给角色**（日记区块里）：
  - **最近 N 天**（默认 3，照故事日期，以现在这个聊天最新的日期算）每回送全文。
  - **更早的**平常不送；聊到相关的事（记事里的名字、日记的地点，或矢量找到意思接近的）时，最多找回几段（默认 2）。找回了哪几段，在「🔍 这一回送了什么」看得到。
  - **🗜️ 压过的日子**送压缩版。
  - **🗺️ 大纲**：写完日记会自动写一份很短的大纲，每回都送，让角色知道你们一路走过什么。可以改、重写、删除；日记改过了会提醒你大纲可能旧了。
  - 这个聊天如果也有带来的「前情提要」，内容可能和日记重复，会提醒你只留一个。

### 💬 你的偏好（设置 › 你的偏好）

你在 OOC（剧情外的说明）里对角色的**长期要求**，例如「希望他更主动」「别一直重复我的话」，可以记成一张清单，**每回提醒角色**。清单跟着角色卡，换新聊天也在。
- 可以自己写，也可以打开「**自动记下**」（默认关）：摘要和写日记时让模型顺便挑出来（同一次调用，不多花钱）。一次性的指示（这段写长一点、继续）不会记。记下时会跳通知。
- 每一条可以**暂停**、**编辑**、**删除**。删掉的之后不会再被加回来。
- 不管有没有打开，OOC 都不会写进摘要和日记。

### 补建旧楼层

摘要分页 →「补建旧楼层」：
- **范围**、**最近几层一层一层细摘**、**更旧的每几层写成一章**（粗略，但省很多次调用）。
- 开始前会显示预估的调用次数和 token，以及「还会发送的标签」，可以当场改成不读。
- 开始或继续前会先找出可能是**番外／小剧场／IF 线**的楼层，列出来让你选 👻 跳过、⭐ 小剧场（默认）或照常摘要。
- 进度会记住，切 App 或关掉后回来可以接着做。
- **先换成便宜的自订 API 再补建**。

粗略补建的章可以之后按「改成逐层细摘」。

### 🩺 检查

找出：没摘要、失败、过期、摘要太长或太短、重复的记事、数量 0 的物件、过期的章和卷…。每一项都有修正按钮，也可以「全部修正」。还可以请模型抽查几层摘要写得对不对。

### 资料管理（设置 › 资料管理）

- **🛟 自动备份**（默认开）：每天第一次打开聊天时，和摘要每多 50 层时，自动把这个聊天的恋人手帐数据（摘要、记事、日记、行事历、回忆录、你的偏好…）存一份，不含聊天原文。每个聊天留最近 7 份，旧的轮流盖掉。三个数字都可以改，填 0 就是不看天数或层数。
  - 存在**酒馆自己的文件夹**（user/files），换浏览器、清缓存都还在。存不进去时改存在这个浏览器里，画面上会写清楚。
  - 「全部备份」可以看每一份的时间、摘要几层、存在哪，选一份**放回**。放回之前会先把现在的样子存一份（「放回／导入之前的样子」），选错了可以再换回来。
- **🚨 防失忆警报**：打开聊天时，如果摘要比最新的备份少了一半以上，会跳提醒（大窗口最上面也有），按「从最新的备份放回」就回来了。处理之前不会自动备份，免得坏掉的样子把好的备份挤掉。自己在这里删除、导入的不算。
- **📦 一键备份全部聊天**：选「这个角色的全部聊天」或「所有角色的全部聊天」，不用打开聊天，打包成一个档下载。只放有恋人手帐数据的聊天。导入时在「导入备份」选这个档：现在开着的聊天马上放回，其他聊天等你打开时自动放回。
- **导出备份**：这个聊天的恋人手帐内容存成 `.json`（可以选择包含设置，**API 密钥一定不会放进去**）。
- **导入备份**：合并（只补没有的）或覆盖。可以用来换设备、在 SillyTavern 和 TauriTavern 之间搬、开分支聊天时带过去。
- **重新检查番外**：检查所有楼层，一键设成 👻 跳过或 ⭐ 小剧场。
- **删除本窗口的内容**：会先自动下载备份。聊天本身不动，和其他聊天共享的记事不清。

### 调用记录（设置 › 调用记录）

恋人手帐自己每次调用模型都会记下：用途、模型、发送／回复 token、花几秒、成功或失败。可以看今天、近 7 天、近 30 天，以及各模型、各用途的统计，比较模型时很好用。不包含你平常聊天本身。

### 外观（设置 › 一般 › 外观）

- **跟随酒馆主题**（默认）：颜色跟着你的酒馆主题。
- **📒 日系手帐・奶油**：方格纸的底、纸胶带、索引贴的分页、粉圆字体、回忆录卡片上贴一段纸胶带。
- **🌱 草地绿**：浅绿渐层和小山丘、标题列下缘一排草丛、叶子形的分页、角落有小叶子的卡片、回忆录的四叶幸运草贴纸。
- **☁️ 天空蓝**：蓝天白云的渐层、标题列的太阳和云、云朵般的胶囊分页、角落有小云的卡片、回忆录的云朵和太阳贴纸。
- **🌸 花朵粉色**：粉色渐层和大朵樱花、小花花圈的标题列、花瓣胶囊分页、角落有小花的卡片、回忆录的压花贴纸。
- **🌙 夜间护眼**：淡绿、浅蓝、粉色三种。深色但不是全黑、字不是纯白，晚上看不刺眼。
- 选了手帐风可以另外勾「聊天里的摘要区块也套用」。字体要连网加载，载不到会用系统字体。

### 好几组 API（设置 › 模型来源）

- **其他 API 组合**：除了上面那组自订 API，可以再存几组（每组有名字、网址、Key、模型，一样可以拉取模型、测试连接）。
- **每种工作用哪一组**：单层摘要和小剧场、章卷压缩、补建、写日记、日记再压一次、其他，各自选「跟默认」「酒馆主 API」或任何一组。例如日常摘要用便宜快速的，压缩和再压一次用细腻的。
- **失败时改用**：连不上、逾时、空回时，自动改用另一组再试一次。
- 调用记录会记每次实际用了哪个模型。Key 只存在这台设备的设置里，备份不会带出去。

### 系统提示词（设置 › 模型来源）

- 「**说明这是成人虚构故事**」（默认开）：告诉模型这是成年人、双方同意的虚构故事，亲密的段落照实、不露骨地记下，比较不会拒绝或回空。
- **自订前言**：可以贴你自己默认里的说明。

## 省钱小技巧

1. **摘要用便宜的自订 API**，聊天用你喜欢的主模型。
2. **设好要跳过的标签**：状态栏、思维链、排版、生图提示通常占掉一大半，跳过或「只当参考」。
3. 摘要模式选「**开始下回前**」：重新生成、swipe 时不会白摘。
4. 补建时，旧的部分用「每几层写成一章」的粗略方式。
5. 记事很多时开「只发送相关的」。
6. 看「调用记录」找出哪个用途、哪个模型最花。

## 常见问题

**模型一直回空的、或显示服务商的通知（例如「响应内容为空」）**
- 可能是内容被模型的安全过滤挡掉。换一个比较宽松的模型或服务商，或确认「说明这是成人虚构故事」有开着。
- 恋人手帐会自动重试 2 次。只回了服务商通知的，不会被当成摘要存进去。

**等太久（逾时）**
- 自订 API 默认等 120 秒，可以在「设置 › 模型来源」调长（最多 600 秒）。会「先思考」的模型通常比较慢。

**「模型把输出额度都用在思考上」**
- 会思考的模型把额度花在思考上，没写出内容。恋人手帐会自动加倍额度再试；还是不行的话，换一个不用思考的模型。

**部、卷的重新压缩一直失败**
- 按「保留现在的总结」，或筛选「失败／过期」后「全部保留」。

**摘要分页上方的「失败」「过期」数字对不上**
- 数字包含章、卷、部，点进去会列出来。

**大窗口打不开、只看到一行字、被主题盖住**
- 先确认已更新到最新版（看版本号）。如果还是不行，截屏给开发者。

**更新后没变化**
- 刷新一次页面。TauriTavern 有时要整个 App 重开。

**记事里出现「（这条记事已删除或合并）」**
- 那是指向已经被删掉或合并的记事的旧变化，数据已经并到留下的那条，不用处理。

## 数据和隐私

- 摘要存在**每一则消息里**（跟着聊天文件走），章、卷、记事、行事历等存在**聊天的数据**里；设置存在酒馆的设置里。
- 除了你选的模型 API（和你开的矢量 API），恋人手帐不会把数据送到其他地方。
- **API 密钥是以明文存在酒馆的设置里**，和酒馆其他设置一样。分享设置档或截屏时请注意；导出的备份不含密钥。
- 删除恋人手帐的内容不会动到聊天本身。
